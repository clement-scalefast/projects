# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through [GitHub's vulnerability reporting form](https://github.com/clement-scalefast/projects/security/advisories/new). Include the steps to reproduce the problem and what an attacker could do with it.

You should get a reply within a week. Once a fix is released, the report is published with credit to you, unless you prefer to stay anonymous.

## Supported versions

Only the latest commit on `main` receives security fixes.

## Scope

The demo accounts and their shared password are sample data for local development and are not a vulnerability. Remove them before deploying the app anywhere reachable by others.
